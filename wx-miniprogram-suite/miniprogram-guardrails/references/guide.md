# 小程序开发红线与避坑指南（完整版）

> 适用：微信小程序（含云开发）。本文件只记**网上查不到、或查到了也容易忽视的致命项**；通用入门知识（生命周期、wxml 基础）自行查官方文档，不在此重复。
>
> **范围说明**：第 1~10 章为**通用红线**（任何小程序都适用）。末尾「附录 A」为**某个具体项目（掌柜好助手）的私有符号示例**——新项目里这些符号不存在，请只取其原则。本文件由多个小程序项目的真实踩坑沉淀（含一次"云同步一天烧 4 万次免费额度"的事故）。

---

## 0. 总纲（先读这条）

小程序的坑分两类：
- **A 类（真机才暴露）**：模拟器、lint、IDE 全不报，真机直接白屏/崩。
- **B 类（运行后才暴露）**：代码能跑、功能"正常"，但**后台在静默烧钱/烧额度/累积脏数据**，本地完全看不出来，只有云控制台能发现——往往发现时已经欠费或污染。

本指南重点防 B 类，也覆盖 A 类里最阴的真机语法坑。

## 1. WXML 编译期硬约束（写了就静默失效 / 或编译直接报错）

### 🔴 红线 1-1：`{{}}` 内不支持方法调用、不支持动态绑定处理函数名
- 所有派生值（视觉映射、合计、进度、类名）**必须在 JS 里预计算成字段**，wxml 只绑定字段。
- 动态方法统一走 `onMainAction` 这类 switch 入口（`bindtap="onMainAction"` + `data-action`），不要写 `bindtap="{{item.fn}}"`。

### 🔴 红线 1-2：`{{}}` 内禁止中文属性名
- `{{counts.待派单}}` 之类编译直接报错（`unexpected ❖`）。所有带中文的键必须预计算成 ASCII 字段（如 `counts.pending`）。

### 🔴 红线 1-3：`wx:key` 不能写 `"index"`
- 会被当属性名（item 上没有 `index` 属性）→ 等于没 key，列表更新错乱。列表无唯一字段时，在渲染数据里生成 `_k`（如 `'sku'+idx`），**且不要写进 storage**。

### 🔴 红线 1-4：WXML 没有 `<b>` 组件
- 加粗一律 `<text class="b">…</text>`（`.b{font-weight:800}`），带其它 class 时 `<text class="b 原class">`。WXML 只允许官方组件（view/text/button/input…）。

### 🟡 务必 1-5：sitemap.json 官方已下线
- `app.json` 不再声明 `sitemapLocation`，`project.config.json` 不再保留 `checkSiteMap`。

## 2. 真机兼容性红线（A 类，模拟器测不出）

### 🔴 红线 2-1：禁用 `?.` / `??` / `||=` / `&&=`
- 真机基础库 **Babel 不转换**这些运算符 → 真机直接 `SyntaxError` 白屏；模拟器、lint、IDE 全不报。
- 对象展开 `{...x}` 可以放心用。

### 🔴 红线 2-2：代码压缩开关**两处都要 true**，禁止手改源码"压缩"
- `project.config.json` 与 `project.private.config.json` 的 `minified/minifyWXML/minifyWXSS/es6/postcss` 都要开；JS 压缩只在**上传时**生效。手改源码做"压缩"= 维护灾难，禁止。

## 3. 小程序平台能力约束（导入/导出 / 跳转 / 原生组件 / 样式）

### 🔴 红线 3-1：跳转 tabBar 页面必须用 `wx.switchTab`
- `navigateTo` 跳 tabBar 页面会**静默失败**（不报错但页面不动）。跳转前先查 `app.json` 的 tabBar 列表决定用哪个 API。统一走项目封装的 `goPage` 类方法，禁止页面里手写 `wx.navigateTo/switchTab`（只有清缓存重启用 `wx.reLaunch`）。

### 🔴 红线 3-2：文件导入/导出的平台边界
- **导入**：`wx.chooseMessageFile` 让用户从聊天/文件 App 选文件（Excel/CSV/txt/PDF），拿临时路径后用 `wx.getFileSystemManager()` 读；表格用 `xlsx.mini` 前端解析，无需后端。⚠️ iOS 只能读「文件」App 共享给微信的文档。
- **导出**：手机端**不能**直接写系统 Download 目录，生成文件默认在小程序沙盒，别的 App 看不到。正确做法：前端生成 → `wx.openDocument()` 唤起预览 → 用户在预览页转发/存文件助手。**PC 端微信小程序**有专属 `wx.saveFileToDisk`，可直接「另存为」到电脑磁盘，体验最好。

### 🔴 红线 3-3：原生组件 input/textarea 禁止垂直 padding
- 会裁字。用固定 `height` + 水平 `padding` 控高。带 fixed 底部导航的页面尾部必须放 safe 占位 view（如 `.anav-safe`），否则最后一段内容滚不出来。

### 🟡 务必 3-4：全局 wxss 类新增前先 grep
- `app.wxss` 是全局类总库，新增类名前先 grep 是否已存在，避免同名双定义互相污染样式。

### 🟡 务必 3-5：`flex` 简写里禁止用 `calc()`
- `flex: 1 1 calc(50% - 8rpx)` 在真机上整条声明失效，卡片变成一行一个。栅格统一：容器 `display:flex;flex-wrap:wrap;justify-content:space-between;`，子项 `width:48.5%;flex:none;`。`width:calc(...)` 安全；`gap` 在老 WebView 不可靠，栅格别依赖它。

## 4. 云开发 / 云函数（最贵、最隐蔽，本文件第一重点）

### 🔴 红线 4-1：后台同步/轮询**禁止固定短间隔盲轮询**，必须"事件驱动 + 无变化退避"
- **事故**：`setInterval(15s)` 每轮无条件 `pull` 一次，开着模拟器/工具一天烧 **4.2 万次**云函数调用；免费额度 20 万/月，只够开 **5 天**，上架后每个真实用户都会这样烧。
- **正确做法**：
  - 同步节奏交给**递归 `setTimeout`，带空闲退避**：基础间隔 60s；连续 N 轮（如 10 轮≈10 分钟）无任何本地推送/拉取变更 → 退避到 5 分钟。
  - 本地有数据写入时立即唤醒回快速节奏；切回前台（`onShow`）立即拉一次。
  - `pull` 因为"远端变化本机无从判断"只能按间隔拉，但间隔要**稀疏**（快模式 2~3 分钟、空闲 10 分钟足够）。
- **额度自检**：云函数 `调用次数`（20 万/月）是**唯一会爆**的免费资源；容量/存储/流量几乎不会超（实测≈0）。架构阶段就要算这笔账。

### 🔴 红线 4-2：所有"出站到云端"的数据**必须在唯一出口统一清洗**
- 云数据库**禁止空字段名**。墓碑按账套分桶时 `spaceId` 为空的记录会进 `''` 桶，原样上传 → 服务端 `update` 直接 `-502001 empty field name`，整次失败。
- **只修一条通道=修一半**：`cloudPush`、`cloudMerge`、备份导出都要过同一清洗函数（剔除空桶、`undefined`、空字符串）。改完用 grep 核对所有出站 payload 组装点。

### 🔴 红线 4-3：云端返回的值**一律当不可信，读取处统一数字化**
- 事故：`safetyBalance` 本地被清掉后，`pull` 用云端脏值（非数字）覆盖回来，`calcHome` 直接 `toFixed` → 整页崩。
- 规则：所有从云/备份回读的数字键，读取处必须 `Number(x)` + `isFinite` 兜底回退默认值。

### 🔴 红线 4-4：演示数据 / 初始化数据**必须幂等**
- 事故：重导生成**新 id** 的应收并推上云；清空本地却没把墓碑推上云 → 云端只增不减，本地清掉的脏数据被 `pull` 复活。
- 规则：重导必须"先清本地再写"且**清云与清本地同一事务**（清完立即推墓碑上云）；演示记录用**固定 id**。

### 🔴 红线 4-5：共享内存内部状态**只能重置 `{}`，绝不置 `null`**
- 事故：缓存层被置 `null`，而读存储处 `key in _c` 遇 `null` 直接抛错，把自动同步循环里所有读存储全打崩。
- 规则：缓存层归零必须 `={}`；存储入口加防御兜底——外部谁误置 null 也不会打崩全 app。

### 🟡 务必 4-6：上线前留一个**云同步一键关闭开关**
- 常量 `CLOUD_DISABLED`（调试期 `true` → 云能力完全不初始化，调用归零；上线前必须改 `false`）。

### 🟡 务必 4-7：压测/调试时**盯云控制台"资源使用"页**，别只看 IDE 控制台
- IDE 控制台能看到日志刷屏，但**看不到调用量数字**；配额消耗是 B 类坑，只有云后台可见。

## 5. 数据层 / Storage

### 🟡 务必 5-1：统一走带前缀的 `S/L` helper，**别在 key 里手写前缀**
- 手写前缀会和自动前缀叠加，数据静默写不到也读不出。读写统一走项目的存储封装。

### 🟡 务必 5-2：遍历键表逐键 `Array.isArray` 再操作
- 键表里混有数字型和对象型键，不判类型直接 `.forEach` 会崩。备份/清理/复制账套遍历必须逐键守卫。

### 🔴 红线 5-3：写操作的辅助方法**禁止引用调用方局部变量**
- 外层 `try/catch` 会吞掉 `ReferenceError` → 一半成功一半静默失败，极难排查。辅助方法只依赖入参与全局状态。

### 🟡 务必 5-4：口径唯一入口
- 所有"算钱"的函数只在 `app.js` 有一份实现，页面只读不另算；多处显示同一数字必须同源。

## 6. 交互 / 视觉红线

### 🔴 红线 6-1：写操作统一点击锁，同一表单的多个提交入口**共用同一把锁**
- 两把不同锁 = 交替连点能开出两笔一样的单。

### 🔴 红线 6-2：**禁止在 `wx.showModal` 的 success/complete 里同步再弹 modal**
- 前一个未关完，第二个静默失败，表现为"点了没反应"。必须 `setTimeout ≥300ms` 延后弹。

### 🔴 红线 6-3：弹层内 canvas（二维码等）**禁止和固定按钮排同屏挤压**
- 原生同层组件在夹缝处部分机型会浮到按钮上层盖住它。多步流程用分步视图，canvas 跟随该步 `wx:if` 渲染。

### 🟡 务必 6-4：浮层/气泡高度**用 `createSelectorQuery` 实测**，不按文案行数估
- 估小了按钮会被 tabbar 挡住。底部目标气泡优先放上方，预留安全区给 tabbar/手势条。

### 🟡 务必 6-5：单行 `<input>` 必须同时给 `height` 与**同值 `line-height`** + `text-align:left`

### 🔴 红线 6-6：导航只走项目封装的 `navTo/switchTo/redirectTo/reLaunch`；**禁止两段式导航**（先切中间页再二次跳）
- TabBar 不能带 query，跨页传参用 Storage 键。自定义返回一律不加。

## 7. 文案红线（对外承诺 = 实现）

### 🔴 红线 7-1：没有的功能**不许写**进介绍/按钮
- 无真 PDF、无打印 API → 禁止"导出 PDF""支持打印"；云能力仅在就绪时可承诺；本地 AI 模板不得写成"云端模型处理"。

### 🟡 务必 7-2：术语/品牌全站统一
- 一处定义，全站复用，禁止各页面自留一份。

## 8. 提审 / 上架红线

### 🔴 红线 8-1：虚拟支付需**小程序先发布**才能申请
- 首次提审版支付未接通，必须置"即将开通"状态，否则点一下不付钱就开通 = 绕开虚拟支付 = **拒审**。
- 企业主体**可开通**虚拟支付（个人主体现在也已开放）。企业主体可用原生客服 `open-type="contact"`。

### 🟡 务必 8-2：改价/改档位**同步三处**
- 客户端常量 + 云 `pay` 配置 + MP 后台道具价。漏一处=服务端二次校验拒发货。

## 9. 工程纪律（交付前必跑）

### 🟡 务必 9-1：提交前跑回归闸门脚本 + 本 skill 的红线审计
- 语法/路径/导航绑定/Storage 键闭环/演示数据核算脚本。改 wxml 绑定或导航必跑交互审计。
- 运行 `scripts/lint_redlines.ps1 <miniprogram-src-dir>` 自动捕获：真机语法、`wx:key="index"`、动态 `bindtap={{`、flex 简写含 `calc`、`navigateTo`（待核 tabBar）。

### 🔴 红线 9-2（AI 协作纪律）：验证 bug **先核实磁盘代码，不甩锅运行环境**
- 看到"模拟器还在跑旧代码""你环境有问题"这类推断，**先确认磁盘上修复是否在、再下结论**。
- 风险要在**设计阶段算账**（如"15s 轮询 × 24h × 用户数 = 多少额度"），不要等用户从云后台发现。
- 代码里已有的异常日志（如每轮"同步完成"刷屏）是**信号**，主动追因，不要当成正常噪音放过。

## 附录 A：某具体项目（掌柜好助手）私有符号示例

> ⚠️ 以下符号**只在该项目存在**，仅作"原则如何落地"的示例，新项目不要照搬符号，照搬原则。

- Storage 封装 `app.S(key)` / `app.L(key, def)`，自动加 `xwv14_` 前缀（手写前缀会双重叠加）。
- 点击锁 `app.lockClick(key)`；同一表单多入口共用一把锁（如 `order_submit`）。
- 金额口径唯一入口 `app.monthProfit/fixedMonthly/recRemain/dueDays`。
- 云同步出口 `cloudPush/cloudMerge`，清洗函数统一剔除空字段名/`undefined`/空串。
- 演示数据三账套 `sp1/sp2/sp3`，固定 id 幂等；`CLOUD_DISABLED` 一键关云同步。
- 导航 `app.navTo/switchTo/redirectTo/reLaunch`；TabBar 传参走 Storage 键 `xwv14_bills_focus` 等。
- 品牌「掌柜好助手」、会员档位对外称「体验版/体验 N 天」、术语对外称「老账本」。
